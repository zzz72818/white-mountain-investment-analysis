# White Mountain Investment Decision Analysis

## Overview

This project analyzes a real estate development investment case involving Recreational Properties and the White Mountain Ski Area project.

The analysis evaluates strategic investment decisions under uncertainty using decision trees, expected value modeling, and sensitivity analysis.

---

## Business Problem

Recreational Properties must determine whether to proceed with the White Mountain Development Project under uncertainty regarding:

- Government lease approval
- Environmental lawsuit outcomes
- Future project reputation
- Development investment risk

The company also evaluates the value of extending land purchase options to delay investment decisions until additional information becomes available.

---

## Analytical Methods

- Decision Tree Analysis
- Expected Value (EV) Modeling
- Sensitivity Analysis
- Scenario Analysis
- Strategic Investment Evaluation
- Option Extension Valuation

---

## Key Analyses

### Investment Decision Evaluation
Compared:
- Proceeding with White Mountain Development
- Alternative guaranteed investment opportunity

### Sensitivity Analysis
Evaluated how:
- Lease approval probability
- Reputation probability
affected project value and strategic recommendations.

### Option Extension Valuation
Calculated the value of:
- One-year option extension
- Six-month option extension

to reduce uncertainty and improve investment timing decisions.

---

## Key Findings

- The conservationists’ lawsuit significantly reduced expected project value.
- Delaying the investment decision increased strategic flexibility and reduced downside risk.
- The expected value of the project was highly sensitive to lease approval probability.
- Option extensions created measurable economic value by improving decision quality under uncertainty.
